# Fitness Tracker App

A simple web app to log daily fitness activities and view progress.

## Features

- Log activities: type, duration, calories, and optional steps
- Dashboard showing today’s:
 - Total steps
 - Number of workouts
 - Calories burned
- Weekly progress bar (active days out of 7)
- List of recent activities
- Data saved in browser using **localStorage**

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage (no backend required)

## How to Run

1. Download or clone this repository.
2. Open the `Fitness-Tracker-App` folder.
3. Open `index.html` in any modern browser.
4. Log activities and see your dashboard update automatically.
