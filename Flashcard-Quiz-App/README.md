# Flashcard Quiz App

A responsive Flashcard Quiz App built using HTML, CSS, and JavaScript.

## Features

- Display one flashcard at a time
- Show and hide flashcard answers
- Next and previous navigation
- Add new flashcards
- Edit existing flashcards
- Delete flashcards with confirmation
- Save flashcards using browser localStorage
- Responsive design for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript
- localStorage

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Or use the Live Server extension in VS Code.
