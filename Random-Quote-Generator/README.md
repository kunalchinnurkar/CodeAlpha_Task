# Random Quote Generator

A clean and simple web app that displays a random motivational quote.

## Features

- Shows a random quote automatically when the page opens
- Includes a **New Quote** button
- Displays the quote text and author name
- Does not repeat the current quote on the next click
- Clean, responsive, and minimal user interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the `Random-Quote-Generator` folder.
3. Open `index.html` in any web browser.
4. Click the **New Quote** button to display another quote.
