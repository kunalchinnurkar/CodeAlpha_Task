# Language Learning App

An interactive Spanish language learning web app built with HTML, CSS, and JavaScript.

## Features

- Learn Spanish vocabulary through flashcards
- View Spanish words, English translations, categories, and example sentences
- Hear word pronunciation using browser speech synthesis
- Browse categories:
 - Greetings
 - Food
 - Travel
 - Grammar
- Mark words as learned
- Track learning progress with a progress bar
- Take a multiple-choice vocabulary quiz
- Save learning progress using browser localStorage
- Reset saved progress when needed

## Technologies Used

- HTML
- CSS
- JavaScript
- Web Speech API
- LocalStorage

## How to Run

1. Download or clone this repository.
2. Open the `Language-Learning-App` folder.
3. Open `index.html` in a modern web browser.
4. Choose a category, practice flashcards, listen to pronunciation, and take quizzes.
